# Личный новостной агент в Telegram

Дважды в день (08:00 и 20:00 МСК) присылает сводку новостей с объяснениями: что произошло и почему это важно. Между сводками пишет, только если случилось что-то действительно срочное. Отвечает на вопросы обычным сообщением с учётом последней сводки.

Рубрики: Россия, ЦБ и рынок · ЦФА и токенизация · AI и финтех · Мир и геополитика. Плюс рынки, почта и календарь.

---

## 1. Что понадобится

- **Токен бота** от [@BotFather](https://t.me/BotFather): `/newbot` → имя → токен вида `123456:ABC…`.
- **Ключ Claude API** на [platform.claude.com](https://platform.claude.com) (Settings → API Keys). Нужен положительный баланс: бот тратит ~$1–10 в месяц, см. раздел 4.
- **Сервер в стране, где работает Claude API** ([список](https://www.anthropic.com/supported-countries)). Россия в список не входит: с российского сервера бот не сможет обращаться к Claude. Подходят Netrun (серверы не в России), любой VPS в Германии, Нидерландах и т. п. Хватит 1 ГБ RAM.
- По желанию:
  - **Почта**: для Gmail — [пароль приложения](https://myaccount.google.com/apppasswords) (нужна двухэтапная аутентификация) и включённый IMAP в настройках Gmail.
  - **Календарь**: Google Calendar → настройки календаря → «Секретный адрес в формате iCal».

## 2. Установка

### Вариант А: Netrun (как Finance bro)

1. Залейте папку в новый репозиторий на GitHub (`.env` и `data/` в `.gitignore` и не попадут туда).
2. В Netrun: новый проект → из GitHub → этот репозиторий. Netrun сам поставит `requirements.txt` и запустит `python main.py` (без аргументов = `serve`).
3. **Секреты**: в панели проекта создайте файл секретов с именем `.env` и заполните его по образцу `.env.example`. Обязательно добавьте строку `DATA_DIR=/data`: папка `/data` на Netrun переживает перезапуски, и в ней хранятся состояние, расходы и логи.
4. **chat_id**: оставьте `TELEGRAM_CHAT_ID` пустым, запустите проект и напишите боту `/start`. Он пришлёт ваш chat_id. Впишите его в секреты и перезапустите проект.
5. Проверка: в консоли Netrun (если она есть) выполните `python main.py check`. Иначе напишите боту `/sources` и `/digest`.

### Вариант Б: свой VPS (systemd)

```bash
scp -r newsbot user@server:/opt/newsbot      # или git clone
ssh user@server
cd /opt/newsbot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env            # ключи и токен
.venv/bin/python main.py chat-id             # сначала напишите боту что-нибудь
nano .env                                    # впишите TELEGRAM_CHAT_ID
.venv/bin/python main.py check               # всё должно быть ✅
.venv/bin/python main.py digest --dry-run    # пробная сводка в консоль, ничего не отправляет
sudo cp deploy/newsbot.service /etc/systemd/system/
sudo nano /etc/systemd/system/newsbot.service   # проверьте User и пути
sudo systemctl daemon-reload
sudo systemctl enable --now newsbot
journalctl -u newsbot -f                     # логи; ещё — data/newsbot.log
```

### Команды

```
python main.py serve                                      # бот + расписание (по умолчанию)
python main.py digest [morning|evening|auto] [--dry-run]  # --dry-run печатает в консоль и не меняет state
python main.py alerts [--dry-run]
python main.py check     # ленты, котировки, почта, календарь, Claude API, Telegram — ✅/❌
python main.py chat-id   # chat_id из последних сообщений боту
```

В Telegram: `/digest`, `/alerts`, `/status`, `/sources`, `/help`. Любой другой текст — вопрос.

Тесты: `pip install -r requirements-dev.txt && pytest`.

## 3. Как менять рубрики, ленты, пороги и время

Всё в `config.yaml`, с комментариями. После правки перезапустите бота.

- **Время**: `schedule.morning` / `schedule.evening`; проверки срочного — `schedule.alerts_hours` и `alerts_minutes`.
- **Ленты**: список `feeds`. У каждой ленты есть `name`, `url` (или `google_news: "запрос"` + `lang: ru|en`) и `topic` (ключ рубрики). Необязательные поля: `max_items`, `priority: high`, `window_hours`.
- **Рубрики**: `digest.rubrics`. Чтобы добавить рубрику, допишите `{key: …, title: …}` и укажите этот `key` в `topic` нужных лент.
- **Котировки и пороги**: список `markets`, поле `alert_pct` — изменение за день в процентах, при котором приходит срочный алерт. Повторный алерт по тому же инструменту приходит только при следующем кратном пороге (2,5% → 5% → 7,5%).
- **Профиль читателя**: `profile`. Он подставляется во все промпты.
- **Объём сводки**: `digest.items_min/items_max`, `morning_chars`, `evening_chars`.

## 4. Сколько стоит и как сэкономить

Примерная оценка на Sonnet 5.5: одна сводка ≈ 30–40 тыс. входных токенов, ≈ 6 тыс. выходных (вместе с «размышлениями» модели) и 3–4 поиска, итого ≈ **$0,15–0,20**. За месяц ≈ **$9–12** на сводки. Фильтр срочного на Haiku 5.5 стоит меньше $0,5 в месяц, вопросы оплачиваются отдельно.

Точный расход виден в `/status`, все вызовы записываются в `data/usage.jsonl`.

**Встроенная защита**: при 80% от `budget.monthly_usd` бот отключает веб-поиск, при 100% перестаёт вызывать Claude до конца месяца и шлёт запасные сводки (котировки и заголовки).

Как сэкономить, от простого к радикальному:
- `models.digest_effort: low`: модель меньше «размышляет».
- `web_search.digest_max_uses: 2` или `web_search.enabled: false`: каждый поиск стоит $0,01, а его результаты увеличивают число входных токенов.
- Меньше лент или `digest.max_items_per_feed: 15`: модель читает меньше.
- `models.digest: claude-haiku-5-5`: примерно в 20 раз дешевле (≈ $0,5–1 в месяц), но объяснения проще.

Для экономии ссылки на новости в модель не передаются, только номера `[n12]`. Модель ссылается на номер, а бот сам подставляет реальный URL. Поэтому выдумать ссылку модель тоже не может.

## 5. Если что-то не работает

- **Лента ❌ в `check`**: часть российских сайтов не открывается с зарубежных IP. Замените ленту на Google News по домену, пример закомментирован в `config.yaml`:
  `{name: Ведомости, google_news: "site:vedomosti.ru when:1d", lang: ru, topic: russia}`.
- **Ошибка версии web search**: бот сам переключается на `web_search_20250305`, а если и это не помогает, работает без поиска (в логе будет запись). Версия задаётся в `web_search.tool_version`.
- **Claude API 403 в `check`**: сервер находится в неподдерживаемой стране. Нужен другой сервер.
- **Gmail не пускает**: нужен пароль приложения, а не обычный пароль, и IMAP должен быть включён (Gmail → Настройки → Пересылка и POP/IMAP). `IMAP_HOST=imap.gmail.com`.
- **Бот молчит**:
  - Проверьте `TELEGRAM_CHAT_ID`: бот отвечает только этому чату.
  - **409 Conflict** в логе означает, что запущены две копии бота с одним токеном (например, локально и на сервере). Остановите лишнюю. При перезапуске на Netrun 409 может мелькнуть на несколько секунд: бот подождёт и продолжит.
- **Котировки Yahoo 429**: Yahoo иногда ограничивает запросы. Бот повторяет запрос, а сводка выходит и без этих цифр.

## 6. Приватность

- В Claude API уходят: заголовки и описания новостей, котировки, события календаря на день и непрочитанные письма за окно. По письмам передаются отправитель, тема и первые ~400 символов текста.
- Чтобы передавать только отправителя и тему, поставьте `mail.send_body_to_claude: false`. Чтобы полностью убрать почту, удалите `IMAP_*` из `.env`.
- Почта открывается только на чтение (`readonly`, `BODY.PEEK`): письма не помечаются прочитанными.
- Секреты лежат только в `.env`. Токен бота, ключ API и пароль вычищаются из логов, а `httpx` пишет в лог только предупреждения, без URL с токеном.
